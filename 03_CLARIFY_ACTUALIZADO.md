# 3. CLARIFY — ACTUALIZADO

## Resoluciones críticas

### Encuestas
- La evaluación diagnóstica anual anterior queda eliminada.
- El reemplazo es un motor general de encuestas institucionales.
- Cada I.E. crea sus propias encuestas.
- Una encuesta puede crearse desde cero o copiarse.
- Copiar crea una encuesta independiente.
- Una encuesta puede reutilizarse en distintos años.
- Puede existir más de una aplicación de la misma encuesta en el mismo año.
- Cada aplicación es independiente.
- Una aplicación no se reutiliza para representar otra aplicación.
- La versión de una encuesta no es una aplicación.
- Una versión utilizada conserva su histórico.
- El acceso del estudiante/docente se realiza mediante enlace y DNI.
- El estudiante debe existir previamente para poder ingresar; si no existe, el Psicólogo debe registrarlo antes.
- El registro inicial del estudiante exige solo datos básicos mínimos; el Psicólogo puede completar más datos opcionalmente.
- El estudiante puede completar datos adicionales dentro de la encuesta.
- La aplicación tiene fecha/hora de inicio y fecha/hora de fin.
- Si vence y se necesita más tiempo, se amplía el fin de la misma aplicación.
- Ampliar el plazo conserva el avance y no crea otra aplicación.
- Si se desea una nueva aplicación, se crea una aplicación independiente.

### Gestión de encuestas
- Global, Director, Administrador I.E., Coordinador y Psicólogo pueden gestionar encuestas.
- Docente no crea, edita ni publica encuestas.
- Respondientes V0: Estudiante y Docente.

## Huecos cerrados técnicamente
- No se crea una tabla por cada enlace temporal.
- No se usa una campaña de encuestas como entidad obligatoria.
- No se usa una tabla genérica de tipos de pregunta.
- No se usa una tabla de componentes visuales.
- No se almacena HTML/React en la base de datos.
- Los componentes visuales pertenecen al frontend.
- Las respuestas y el avance pertenecen a una aplicación concreta.
- La seguridad del enlace y de la aplicación se valida server-side.
- El vencimiento no obliga a duplicar aplicaciones.

## Regla de precedencia
Las decisiones de este documento reemplazan cualquier definición histórica incompatible del diagnóstico anual anterior.
