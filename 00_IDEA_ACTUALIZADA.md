# 0. IDEA — ACTUALIZADA

## Problema
Centralizar la información del estudiante y su acompañamiento psicológico, conservando continuidad histórica entre años e instituciones, y permitir aplicaciones de encuestas institucionales configurables sin depender de formularios externos.

## Objetivo
Sistema seguro y trazable para estudiantes, contexto anual, encuestas institucionales, derivaciones, Casos, Atenciones, necesidades especiales, transferencias, licencias, auditoría y promoción masiva.

## Nueva lógica de encuestas
La evaluación diagnóstica anual anterior queda eliminada como módulo funcional. Es reemplazada por un motor general de encuestas institucionales.

Cada I.E. puede crear sus propias encuestas desde cero o copiando una encuesta existente. Una copia es una encuesta independiente.

Una encuesta puede tener versiones. Una versión utilizada conserva su histórico y no se modifica; si cambia la encuesta, se crea una nueva versión.

Las encuestas se aplican mediante aplicaciones independientes. Una misma encuesta puede aplicarse nuevamente en años posteriores y también más de una vez en un mismo año cuando exista una necesidad. Cada aplicación conserva su propio contexto y ventana de fecha/hora.

El acceso del estudiante o docente se realiza mediante un enlace y DNI. El sistema carga los datos registrados del respondiente.

## Actores
Administrador Global, Director, Administrador I.E., Coordinador, Docente, Psicólogo y estudiante como participante de encuestas.

## Alcance V0
Gestión académico-institucional necesaria para acompañamiento psicológico, historia, permisos, auditoría, operaciones administrativas definidas y motor institucional de encuestas.

## Fuera de alcance
Agenda completa, reservas, pagos/auto-renovación, derivación web asistida, episodios/subcasos complejos, campañas de encuestas, segmentación avanzada, plantillas globales obligatorias, editor HTML libre para instituciones y arquitectura distribuida innecesaria.
